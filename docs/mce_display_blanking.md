# Запрет гашения экрана через MCE

Как не дать системе погасить экран во время игры и как вернуть
штатное поведение при сворачивании/закрытии приложения.

Готовый пример на C лежит в `examples/mce/` — его можно брать
и адаптировать под свой движок (см. «Пример кода» ниже).

## Зачем это нужно

Система гасит дисплей по таймауту бездействия, а бездействие
считается по тач-вводу. Если в игру играют геймпадом (или просто
долго не касаются экрана — катсцены, чтение диалогов), дисплей
гаснет прямо посреди игры. Поэтому приложение, пока оно на переднем
плане, должно запрещать гашение экрана — и обязательно возвращать
штатное поведение при сворачивании и закрытии.

## Как это работает

Питанием дисплея на ОС Аврора (как и на Sailfish OS) управляет
**MCE (Mode Control Entity)**. Он доступен на **system bus**:

- сервис: `com.nokia.mce`
- объект: `/com/nokia/mce/request`
- интерфейс: `com.nokia.mce.request`
- методы:
  - `req_display_blanking_pause` — запретить гашение экрана;
  - `req_display_cancel_blanking_pause` — отменить запрет.

Важные свойства протокола:

- Запрет **временный**: действует около 60 секунд, после чего MCE
  сам возвращает штатное гашение. Поэтому, пока запрет нужен,
  `req_display_blanking_pause` надо **переотправлять периодически**
  (в примере — каждые 55 секунд).
- Вызовы делаются **без ожидания ответа** (fire-and-forget) — игровой
  цикл не должен блокироваться на DBus.
- Вызовы работают из песочницы приложения, дополнительных
  разрешений не требуется (проверено на портах).

## Жизненный цикл в приложении

1. **Старт приложения:** подключиться к system bus и убедиться, что
   сервис MCE присутствует (`mce_keepalive_init`).
2. **Приложение на переднем плане / начало игры:** включить запрет
   (`mce_keepalive_set_prevent_blanking(true)`) — посылается
   `req_display_blanking_pause` и запускается таймер продления.
3. **Главный цикл:** раз в кадр прокручивать GLib main context
   (`mce_keepalive_pump`) — через него срабатывает таймер продления.
   Если проект уже прокручивает GLib-контекст (например, ради
   Maliit-клавиатуры, см. `docs/maliit_keyboard.md`), отдельный
   вызов не нужен.
4. **Сворачивание приложения:** отключить запрет
   (`mce_keepalive_set_prevent_blanking(false)`) — таймер
   останавливается, посылается `req_display_cancel_blanking_pause`.
   Точка привязки: `SDL_APP_WILLENTERBACKGROUND` в SDL2, колбэк
   иконификации окна (`glfwSetWindowIconifyCallback`) в GLFW. При
   возврате на передний план — включить снова.
5. **Штатное закрытие:** отключить запрет и отключиться от шины
   (`mce_keepalive_shutdown`).

Не забудьте п.4–5: если приложение завершилось, не отменив запрет,
экран устройства не будет гаснуть, пока не истечёт последний
60-секундный интервал, — это допустимо, но систематически оставлять
запрет нельзя.

## Пример кода (`examples/mce/`)

- `mce_keepalive.h` / `mce_keepalive.c` — самодостаточный модуль на
  чистом C (внутри — GLib/GDBus на system bus). Никакой привязки
  к движку: копируется в проект как есть.

Публичный API:

```c
bool mce_keepalive_init( void );              // подключение к MCE
void mce_keepalive_shutdown( void );          // отмена + отключение
bool mce_keepalive_is_available( void );
void mce_keepalive_set_prevent_blanking( bool enable );
bool mce_keepalive_get_prevent_blanking( void );
void mce_keepalive_pump( void );              // раз в кадр
```

Типичный цикл:

```c
mce_keepalive_init();
mce_keepalive_set_prevent_blanking( true );
// в главном цикле, раз в кадр:
mce_keepalive_pump();
// на сворачивании (SDL_APP_WILLENTERBACKGROUND и т.п.):
mce_keepalive_set_prevent_blanking( false );
// на закрытии:
mce_keepalive_shutdown();
```

Модуль безопасно деградирует: если system bus или MCE недоступны,
`mce_keepalive_init` вернёт `false`, а все остальные вызовы станут
no-op — игра просто будет работать без запрета гашения.

Замечание к Lua-оригиналу (`aurorahelper.lua` из порта LÖVE):
в нём сообщение отмены запрета ошибочно создавалось с методом
`req_display_blanking_pause` вместо `req_display_cancel_blanking_pause`
— то есть отмена фактически не отправлялась. В C-версии это
исправлено.

## Сборка

Модуль зависит от GLib/GIO. Для сборки нужны:

```
pkg-config --cflags --libs glib-2.0 gio-2.0
```

В spec-файл пакета добавить:

```
BuildRequires: pkgconfig(glib-2.0)
BuildRequires: pkgconfig(gio-2.0)
```
